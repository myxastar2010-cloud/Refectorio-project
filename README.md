# Refectorio

**Сайт-постановщик целей в питании с ИИ.** Пользователь ставит цель, проходит короткий интерактивный тест,
а Refectorio собирает интерактивное меню с блюдами — с научным расчётом норм и ИИ-помощником.

Школьный проект команды **Modern Manifesto** (учащиеся школы #2107). Бесплатный, с открытым исходным кодом.

> Название — от латинского *refectorium*, «трапезная».

## Главный принцип

**ИИ не считает цифры.** Калории, белки, жиры, углеводы и нормы считает проверяемый код (`packages/nutrition-core`)
по научным источникам. ИИ только выбирает блюда из заранее отфильтрованного списка и пишет понятные тексты;
валидатор проверяет каждый ответ, а при сбое работает алгоритм без ИИ.

## Быстрый старт

Нужны Node.js 24 LTS и npm 11.

```bash
npm ci          # установка зависимостей
npm run dev     # сайт на http://localhost:5173
npm test        # юнит-тесты
npm run build   # сборка
```

Все команды — в [`CLAUDE.md`](CLAUDE.md), правила работы — в [`CONTRIBUTING.md`](CONTRIBUTING.md).

## Структура

| Папка | Что внутри |
|---|---|
| `apps/web` | сайт: Vite + React + TypeScript + Tailwind CSS + Motion |
| `packages/nutrition-core` | расчёт норм питания и правила безопасности, с тестами |
| `assets-src` | исходные картинки; `npm run assets` делает из них оптимизированные AVIF/WebP |
| `docs` | документация: [наука](docs/science/), [решения по архитектуре](docs/adr/), [дизайн-система](docs/design-system.md) |
| `scripts` | служебные скрипты |

## Технологии

Vite 8 · React 19.3 · TypeScript 6 · Tailwind CSS 4.3 · Motion 13 · Open Runde · Tabler Icons · Vitest · Playwright · Lighthouse CI.
Хостинг — Render Static Site и GitHub Pages.

## Важно о здоровье

Refectorio не ставит диагнозы и не заменяет врача. Для детей, беременных и кормящих, людей с диабетом, болезнями почек
и расстройствами пищевого поведения функции ограничены, и сервис советует обратиться к специалисту.
