# ADR 0001 · Стек фронтенда

- Статус: принято · 02.10.2026
- Связано: ТЗ этапа 0 (разделы 3, 8), ADR 0006 (анимации), ADR 0007 (тесты)

## Контекст

Главная страница — «лицо» проекта: пиксельная вёрстка по макетам, сложные анимации (летающая еда, смена сцен, раскрытие
карточки как в iOS), 60 fps и бюджеты Lighthouse ≥ 95. На этапах 2–3 добавятся тест, меню, дневник и аккаунты. Команда —
5 школьников, поэтому стек должен быть популярным, с хорошей документацией и без лишних инструментов.

## Решение

- **Vite 8** (сборщик Rolldown) — быстрый дев-сервер и сборка статики для Render Static Site и GitHub Pages.
- **React 19.3 + TypeScript 6.0 (strict)** — компонентный UI, строгие типы. TypeScript 7 не берём: typescript-eslint 8.70
  поддерживает только < 6.1.
- **Tailwind CSS 4.3** — утилиты и токены через `@theme`; сложная масштабируемая геометрия сцен — в CSS на токенах.
- **Motion 13** (`motion/react`, `LazyMotion` + `domMax`) — пружины, `layoutId` для shared-element, `AnimatePresence`.
- **Nunito Variable** (самохостинг, OFL), **Tabler Icons** (MIT), **zod 4** для схемы контента.
- npm workspaces (`apps/*`, `packages/*`) без pnpm/yarn — меньше установок у команды.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Next.js / Remix | Нужен Node-сервер или сложная статическая выгрузка; для одностраничной главной — лишнее |
| Astro | Отлично для статики, но интерактивные сцены всё равно на React, второй слой абстракции |
| SvelteKit / Vue | Команда и экосистема анимаций (Motion для React) — в пользу React |
| CSS Modules без Tailwind | Решение ТЗ — Tailwind; токены в `@theme` удобны для этапов 2–3 |

## Последствия

- Статическая сборка (`apps/web/dist`) публикуется без сервера; API этапов 2–3 будет отдельным сервисом (ADR 0002).
- Бюджет начального JS ≤ 150 КБ gzip: Motion подключается через `LazyMotion`, тяжёлые части — `React.lazy`.
- Версии закреплены `package-lock.json`; обновления — осознанно, с прогоном всего контура качества.
