# @refectorio/taste-core

Каталог блюд и модель вкуса для игры «Выберите блюдо». Чистый TypeScript, без интерфейса и ИИ; одинаковый результат
при одном и том же `seed` ([ADR 0008](../../docs/adr/0008-taste-elicitation.md)).

## Что внутри

| Файл | Что делает |
|---|---|
| `data/catalog.json` | 186 блюд: тип, кухня, белки, способы готовки, вкусы, текстуры, знакомость и популярность в России, аллергены |
| `src/model.ts`, `src/stats.ts` | байесовская модель «понравится ли блюдо» (логистическая регрессия с априорным распределением) |
| `src/selection.ts`, `src/engine.ts` | выбор следующей карточки (максимум информации о вкусе), 10 решающих ответов |
| `src/profile.ts` | профиль вкуса для меню (`TasteProfileV1`) и подсказки «вам нравятся супы…» |
| `data/photo-*.json` | фото блюд: выбранные снимки, фокус кадра, лёгкая копия для сайта ([ADR 0011](../../docs/adr/0011-self-hosted-photos.md)) |
| `data/dish-text.json` | описания блюд для карточек игры (этап 3): длинное ≤ 220 и короткое ≤ 90 знаков |
| `data/dish-numbers.json` | ккал, белки, жиры, углеводы на стандартную порцию — считает скрипт `scripts/dish-data` по рецептам и USDA, не ИИ |
| `sim/` | симуляция игры на тысячах виртуальных пользователей (`npm run sim -- --users 5000 --out <папка>`) |

## Проверки

`npm test` проверяет схемы данных (`catalog.test.ts`, `dish-info.test.ts`, `photo-manifest.test.ts`), модель и отбор.
Описания блюд не содержат цифр и слов о пользе для здоровья — это проверяет тест.
