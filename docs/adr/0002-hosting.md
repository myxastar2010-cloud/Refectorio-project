# ADR 0002 · Хостинг: Render Static Site + зеркало GitHub Pages, API во Frankfurt

- Статус: принято · 02.10.2026
- Связано: `00_Анализ-идеи.md` (раздел 7), R11, R12, `render.yaml`, `.github/workflows/pages.yml`

## Контекст

Пользователи — в России. Часть зарубежной инфраструктуры в РФ замедляется: `*.onrender.com` идёт через Cloudflare, который
российские провайдеры ограничивают с 2025 года. Бюджет — 0 ₽. На этапах 2–3 нужен сервер API (ИИ, аккаунты).

## Решение

1. **Фронтенд — Render Static Site** (основной адрес): бесплатно, CDN, не засыпает. Описан как код в `render.yaml`
   (Blueprint): сборка `npm ci && npm run build -w @refectorio/web`, публикация `apps/web/dist`, кэш на год для
   хэшированных файлов `/assets/*`, `no-cache` для `index.html`, заголовки безопасности (CSP, HSTS, nosniff, X-Frame-Options).
2. **Зеркало — GitHub Pages** (workflow `pages.yml`, base из `actions/configure-pages`): независимая инфраструктура на случай
   проблем с доступом к Render из РФ.
3. **API (этапы 2–3) — Render Web Service, регион Frankfurt**: бесплатный сервис засыпает через 15 минут → «будильник»
   (GitHub Actions / cron-job.org пингует `/health` каждые 10–14 минут; 744 ч/мес < лимита 750 ч) и прогрев при открытии теста.
   Браузер общается только с нашим API; ИИ-провайдеры и БД вызываются только с сервера (ключи не попадают в браузер).
4. **Проверка доступа из РФ** — после публикации: `curl` с этой машины и ручная проверка с телефона через мобильный интернет
   без VPN (`refectorio-workspace/reports/stage-0-ru-access.md`).

## Риски и план Б

| Риск | Что делаем |
|---|---|
| Render недоступен/медленный из РФ | Основным адресом становится GitHub Pages |
| GitHub Pages тоже ограничат | Перенос статики в Yandex Object Storage (бесплатная квота 1 ГБ) |
| API засыпает в день защиты | Будильник, прогрев, локальный запуск на ноутбуке, записанное демо-видео |
| Бесплатные лимиты Render | Один сервис 24/7 укладывается в 750 ч/мес |

## Последствия

- Сайт работает и на `/` (Render), и на `/refectorio/` (Pages) — все пути к файлам строятся от `import.meta.env.BASE_URL`.
- CSP разрешает только свои ресурсы (`'self'`); при подключении API на этапе 2 в `connect-src` добавится адрес сервера.
