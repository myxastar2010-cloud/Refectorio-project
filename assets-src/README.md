# assets-src — исходные картинки

Копии исходников команды из `Ресурсы для создания/Задача 1/` (оригиналы там не меняются).
Из этой папки скрипт `npm run assets` (`scripts/optimize-assets.mjs`, sharp) собирает оптимизированные файлы
в `apps/web/src/assets/generated/` и `manifest.json`. Результат коммитится, поэтому сборке на Render и GitHub Pages sharp не нужен.

| Файл | Откуда | Что это |
|---|---|---|
| `food/food-1-strawberry.png` … `food-9-burger.png` | `картинки еды для фона/еда 1–9.png` | 512×512 RGBA: клубника, салат, авокадо, брокколи, попкорн, хот-дог, пончик, яичница, бургер |
| `team/team-card-bg.png` | `дизайн команда подробное.png` | 1401×844, фон раскрытой карточки команды (скругления r ≈ 217 «запечены») |
| `team/team-logo.png` | `логотип команды.png` | 187×187, иконка команды (r ≈ 45) |
| `icons/card-1-school.svg` … `card-4-shield-check.svg` | `иконки для карточек/Карточка 1–4.svg` | Tabler Icons (MIT), filled; в коде используются те же иконки из `@tabler/icons-react` |

## Что делает скрипт

- **Еда:** квадратные спрайты 200 и 400 px (1× и 2×) в AVIF и WebP; заранее размытые копии для второй части
  (σ = 8,5 px на 1×, с прозрачными полями 13% — размытие не обрезается); маски непрозрачности 32×32 для точной проверки кликов;
  границы видимой части спрайта.
- **Команда:** фон карточки без прозрачных углов (углы залиты средним цветом соседних пикселей — приложение скругляет
  сам, с анимацией радиуса) в ширинах 1401 и 701 px; логотип 187 px.

## Что нужно от команды

- Логотип команды и картинка «звезды» в высоком разрешении (от 512 px, лучше 1024 px) — сейчас 187 px, на Retina мыльно.
- Фон раскрытой карточки без «запечённых» скруглений и в 2× (2802×1688).
- Подтверждение лицензий на картинки еды и «звезды» (проект открытый, лицензия MIT).

Как обновить картинку: заменить файл здесь с тем же именем → `npm run assets` → закоммитить `assets-src/` и `apps/web/src/assets/generated/`.
