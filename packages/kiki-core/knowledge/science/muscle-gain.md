Темп набора массы 0,25–0,5 % массы тела в неделю — это практика спортивного питания; отдельных клинических рекомендаций для всех нет, уверенность низкая или средняя [R04 §3]. В меню по умолчанию — 0,25–0,375 % в неделю [R04 §3]. Белок для тренирующихся по ISSN — 1,4–2,0 г/кг в сутки [R02 §1.3], порциями по 0,25–0,40 г/кг каждые 3–4 ч [R17 §3]. Значения выше 2,0 г/кг нужны только в особых сценариях [R02 Коротко].
Осторожность: при болезнях почек белок определяет врач [R08 §1]; подросткам цели по весу ставятся только с педиатром [R04 §6].
Кики подберёт блюда с белком в каждом приёме и не будет рекомендовать добавки и препараты.
