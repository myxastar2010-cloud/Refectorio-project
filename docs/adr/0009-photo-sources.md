# ADR 0009 · Фото блюд: Unsplash по ссылкам сервиса, в git — только метаданные

- Статус: принято · 09.10.2026 (дополнено 11.10.2026)
- Связано: ТЗ этапа 2 (§9.6–9.8), исследование R16 (`refectorio-workspace/research/R16-photo-sources.md`), решение D-037,
  `docs/photo-licensing.md`, `docs/photo-credits.md`, `scripts/photos/`

## Контекст

Игре нужны настоящие, аппетитные фото 186 блюд, включая русские (холодец, шуба, рассольник). Рисовать или
генерировать их нельзя (ТЗ: только реальные фото с понятной лицензией). Код открыт (MIT), репозиторий публичный.
Из части российских сетей зарубежные CDN могут открываться медленно или не открываться.

## Решение

1. **Источник — Unsplash API** (демо-ключ, 50 запросов в час). Pexels был основным по ТЗ, но перестал выдавать новые
   ключи; конвейер для него сохранён и включится, если ключ появится (`curate --provider pexels`).
2. **Подбор — скриптами и глазами:** поиск по английским запросам → фильтр (размер, люди, текст, алкоголь, сырые
   продукты вместо блюда) → листы 6 × 6 → визуальный выбор (одно фото не может служить двум блюдам) → повторный поиск,
   если ничего не подошло. Итог: фото есть у 171 блюда из 186; остальные 15 игра не показывает.
3. **В git — только метаданные** (`photo-manifest.json`): id фото, автор, ссылки, точка кадрирования, средний цвет,
   blurhash, дата выбора и вызова `download_location`. Сайт получает облегчённую копию `photo-runtime.json`
   (19,5 КБ gzip, отдельный чанк), которую проверяет тест на совпадение с манифестом.
4. **Показ — хотлинк** `images.unsplash.com` с параметром `ixid` и размерами 480/720/960 (`fit=crop`, кадр по точке
   интереса, `auto=format`). Подпись «Фото: автор · Unsplash» со ссылками и `utm_source=refectorio` — под каждой карточкой.
5. **CSP:** в `img-src` добавлен только `https://images.unsplash.com`; `connect-src` остаётся `'self'` — к API сайт не
   обращается. E2E проверяет, что запросов к `api.unsplash.com`/`api.pexels.com` нет.
6. **Если фото не грузится** — заглушка из blurhash того же фото (цвета и композиция) с названием блюда; после двух
   неудач подряд игра перестаёт ждать сервис до перезагрузки.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Хранить файлы фото в репозитории или на нашем хостинге | Unsplash требует хотлинк; лицензия Pexels запрещает распространять копии «сами по себе» |
| Сгенерированные ИИ картинки | Против ТЗ: нужны настоящие блюда; риск «неаппетитных» артефактов |
| Только заглушки | Игра теряет смысл: вкус оценивают по фото |
| Wikimedia Commons | Разные лицензии у каждого файла (часто CC BY-SA с требованиями к подписи), неровное качество — оставлено как запасной вариант для «трудных» русских блюд |

## Последствия

- Ключ API живёт только в `.secrets/` вне git или в переменной окружения; pre-commit проверяет, что ключей нет в коммите.
- Замена фото командой — через `photo-overrides.json` и `finalize.mjs`, без правки кода.
- 15 блюд без фото (холодец, шуба, мимоза, манты, бешбармак и др.) — кандидаты на ручной поиск или собственные
  фото команды на этапе 3.
