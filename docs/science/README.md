# Научная основа Refectorio

Эта страница объясняет простым языком, как Refectorio считает нормы питания и почему ему можно доверять.
Полное исследование (13 модулей, 170 источников, независимая проверка 45 ключевых чисел) команда ведёт отдельно;
здесь — главное и ссылки на первоисточники.

> **Refectorio — не врач и не медицинское приложение.** Все числа — оценки (точность формул для конкретного человека — ±10–20%).
> При болезнях, беременности, а также детям — решения о питании принимаются вместе с врачом.

## Главный принцип: числа считает код, а не ИИ

Языковые модели часто ошибаются в калориях. Поэтому в Refectorio:

1. **Нормы считает проверяемый код** (`packages/nutrition-core`) по формулам из научных статей и официальных норм. У каждой формулы есть
   тесты на примерах из первоисточников.
2. **ИИ только выбирает блюда** из заранее отфильтрованного безопасного списка и пишет короткие пояснения — без единой цифры.
3. **Каждый ответ ИИ проверяет валидатор**, а если ИИ недоступен — меню собирает алгоритм без ИИ.

## Цели по весу и безопасный темп

- Снижение веса — по умолчанию **0,5%** массы тела в неделю, не больше **1%**; набор — 0,25–0,5%.
- Калорийность не опускается ниже **1200 ккал** (женщины) и **1500 ккал** (мужчины) без врача; диеты ниже **800 ккал** — только под
  наблюдением врача, сайт их не предлагает (рекомендации AHA/ACC/TOS 2013, Jensen et al., Circulation 2014).
- 1 кг веса ≈ 7700 ккал — это грубая оценка: со временем организм тратит меньше, поэтому прогноз корректируется по реальной динамике
  (Hall et al., The Lancet, 2011 — [doi:10.1016/S0140-6736(11)60812-X](https://doi.org/10.1016/S0140-6736(11)60812-X)).
- Детям и подросткам цели «похудеть» или «набрать» не ставятся — только привычки и полноценное питание для роста.

## Безопасность: кого и как защищает сайт

| Ситуация | Что делает Refectorio |
|---|---|
| Ребёнок до 1 года | Не составляет меню — советует обратиться к педиатру |
| Дети 1–13 лет | Только вместе со взрослым («семейный режим»), без целей по весу |
| Подростки 14–17 лет | Без целей по весу и «диет», данные хранятся только в браузере |
| Беременность, кормление грудью | Без снижения веса и строгих режимов, с советом врача |
| Диабет на инсулине, болезни почек, фенилкетонурия | Персональное меню не составляется — нужен врач |
| Диабет 2 типа, приём варфарина или ингибиторов МАО | Ограниченный режим и совет врача |
| Сложные отношения с едой | Без целей по весу, цифры не в центре внимания, контакты помощи |

Индекс массы тела взрослых оценивается по шкале ВОЗ; для детей 5–19 лет используется z-оценка ИМТ-для-возраста по методу ВОЗ 2007
([данные ВОЗ](https://www.who.int/tools/growth-reference-data-for-5to19-years/indicators/bmi-for-age)) — детям она не показывается как «оценка».

## Аллергены и режимы питания

- 15 аллергенов из технического регламента ТР ТС 022/2011 (совпадают с 14 аллергенами Регламента ЕС 1169/2011, плюс аспартам —
  предупреждение при фенилкетонурии). Аллергия — жёсткий фильтр: блюдо с аллергеном в составе в меню не попадает.
- «Без глютена» — не больше 20 мг/кг (Codex Alimentarius).
- Поддерживаются вегетарианство, веганство (с напоминаниями о витамине B12, D, йоде, омега-3, железе и цинке), православный пост,
  халяль и кошер.
