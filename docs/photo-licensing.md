# Фото блюд и иконки теста — откуда и на каких условиях

Игра «Выберите блюдо» показывает настоящие фотографии блюд. Кода в них нет, а условия использования у сервисов
фотографий строгие, поэтому здесь записано, что мы делаем и почему. Список авторов — [photo-credits.md](photo-credits.md).

## Где хранятся фото

- **В репозитории фото нет.** В git лежат только **метаданные**: `packages/taste-core/data/photo-manifest.json`
  (какое фото у какого блюда, автор, ссылки, точка кадрирования, средний цвет, blurhash-заглушка) и его облегчённая
  копия для сайта `photo-runtime.json`. Ключей API в репозитории тоже нет (pre-commit проверяет: `scripts/check-secrets.mjs`).
- **Фото раздаёт наш сайт** (с этапа 3, [ADR 0011](adr/0011-self-hosted-photos.md)). При каждой сборке скрипт
  `scripts/photos/materialize.mjs` скачивает выбранные фото с сервиса во временную папку `.cache/` (её нет в git),
  обрезает до 3:4 и сохраняет в AVIF и WebP трёх размеров плюс маленькую размытую копию. Эти файлы уходят на хостинг
  вместе с сайтом, и браузер посетителя ни к какому стороннему сервису не обращается.

## Unsplash — на каких условиях

Все 171 фото найдены на [Unsplash](https://unsplash.com/?utm_source=refectorio&utm_medium=referral) и используются
по [лицензии Unsplash](https://unsplash.com/license): фото можно бесплатно скачивать, копировать, изменять и
показывать, в том числе без указания автора; нельзя собирать из них похожий фотосервис.

| Что | Как сделано |
|---|---|
| Лицензия Unsplash | Копии фото показываются в игре как часть сайта, а не как набор фото; в репозиторий они не попадают |
| `download_location` (правила API) | `scripts/photos/finalize.mjs` вызвал его один раз для каждого выбранного фото — для всех 171 |
| Авторы | Все авторы со ссылками — в [photo-credits.md](photo-credits.md); ссылка «Авторы фотографий» — в карточке «О проекте» → «Подробнее» |
| Ключ API | Его читают только скрипты подбора (переменная окружения или папка `.secrets/` вне git); браузер к API не обращается (CSP: `connect-src 'self'`, `img-src 'self' data:`) |

**Сознательное отступление (D-048).** Фото найдены через Unsplash API, а [правила API](https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines)
просят приложения показывать фото по ссылкам сервиса («хотлинк») и подписывать автора под фото
([правило подписи](https://help.unsplash.com/en/articles/2511315-guideline-attribution)). По просьбе команды подпись
из игры убрана, а фото раздаются с нашего сайта по лицензии Unsplash. Плюсы: игра не зависит от того, открывается ли
CDN Unsplash из российских сетей; IP-адрес посетителя не уходит третьей стороне; CSP проще. Если команда решит
вернуть правила API: маленькая подпись внутри описания блюда или флаг сборки `PHOTO_HOSTING=unsplash` (хотлинк с
подписью «Фото: автор · Unsplash», как на этапе 2; для Render ещё нужно вернуть `https://images.unsplash.com` в CSP
в `render.yaml`).

## Pexels — если появится ключ

Сейчас Pexels не выдаёт новые ключи ([страница API](https://www.pexels.com/api/)), поэтому все фото — с Unsplash.
Конвейер готов и для Pexels (`curate --provider pexels`): его фото тоже собираются при сборке. Лицензия Pexels
запрещает распространять копии «сами по себе», поэтому и они не попадают в git.

## Если фото не загрузилось

Если файл фото не пришёл (сеть, ошибка сборки), карточка показывает размытую заглушку из blurhash (цвета и
композиция того же фото, хранится в манифесте) и название блюда. Сборка для публикации останавливается, если не
хватает больше 5 % фото. Блюда без подобранного фото в игре не показываются, но их вкус всё равно предсказывается
по ответам.

## Иконки вопросов и вариантов

Иконки шагов теста (цель, тип питания, образ жизни и другие) нарисованы командой Modern Manifesto с помощью ИИ и
переданы в проект вместе с макетами. Скрипт `npm run quiz-icons` только обрезает их, чистит фон и сохраняет в AVIF и WebP
(`apps/web/src/assets/generated/quiz/`). Условия использования — те же, что у остальных материалов команды
(см. «Лицензия» в [README](../README.md)).

## Как заменить фото

Команда может закрепить своё фото за блюдом: id фото Unsplash в `packages/taste-core/data/photo-overrides.json`
(`{ "d_borscht": { "provider": "unsplash", "id": "…" } }`), затем `node scripts/photos/finalize.mjs` с ключом.
Порядок подбора целиком — в [architecture.md](architecture.md) (раздел о фото).
