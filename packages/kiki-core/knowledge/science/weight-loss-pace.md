Спокойный темп для взрослых — 0,45–0,9 кг в неделю (1–2 фунта) по CDC [R04 §3], что соответствует примерно 0,5–1 % массы тела в неделю [R04 Коротко]. По умолчанию в меню — 0,5–0,7 % в неделю; максимум без дополнительных предупреждений — 1 % [R04 §3]. В исследовании с элитными спортсменами (Garthe, 2011) темп 0,7 % в неделю лучше сохранял мышцы, чем 1,4 % [R04 §3]; для обычных людей вывод переносится осторожно.
Не для всех: подросткам, беременным, кормящим и людям с РПП в анамнезе цель по снижению веса не ставится [R08 §1; R04 §6]; при диабете — только вместе с врачом [quiz.ru.ts].
Кики говорит о «цели по весу» и балансе без осуждения и предложит корректировать план по фактической динамике, а не по формуле [R04 Коротко].
