# `packages/nutrition-core` — исполняемая спецификация расчётов

## Принципы

- Чистый TypeScript: без React, без сети, без ИИ, без `Date.now()` внутри расчётов (дата — параметр).
- Каждая формула и каждое число — со ссылкой на первоисточник в комментарии (`// Source: Mifflin 1990, doi:…`)
  и в `docs/science/`. Нормы по возрастам — в JSON с полями `source` и `version`.
- Единицы — в именах и типах: `weightKg`, `heightCm`, `ageYears`, `energyKcal`, `proteinG`.
- Ошибки ввода — явный результат `Result<T, E>`, а не исключения. Диапазоны ввода проверяются на входе.
- Округление — только на выходе для показа; внутри считаем в полной точности.

## Правила безопасности (`guardrails`)

- Отдельный модуль. Возвращает решение с машиночитаемыми причинами: `allowed`, `limited`, `requiresAdult`, `requiresDoctor`, `refused`.
- Никаких дефицитов калорий для детей и подростков; при ИМТ < 18,5 цель «похудеть» недоступна;
  беременность, лактация, диабет, болезни почек, признаки РПП — ограниченный режим и совет обратиться к врачу;
  младенцы до 1 года — вне продукта.
- Любое изменение порогов — только со ссылкой на источник из `refectorio-workspace/research/` и с обновлением тестов.

## Тесты

- Эталонные примеры из первоисточников, граничные значения, свойства (монотонность, неотрицательность),
  эталонные персоны (`test-personas.json`).
- Покрытие ≥ 95% строк; `guardrails` — 100% веток.
