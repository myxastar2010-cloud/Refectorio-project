# ADR 0004 · Аутентификация: Better Auth, вход через VK ID и Яндекс ID

- Статус: принято (реализация — этап 3) · 02.10.2026
- Связано: R12, `research/conflicts.md` C-02, D-012, ADR 0003

## Контекст

С 01.12.2023 владельцы российских ресурсов обязаны авторизовывать пользователей только через российский номер телефона,
Госуслуги/ЕБС или системы российских владельцев (ч. 10 ст. 8 149-ФЗ в редакции **406-ФЗ от 31.07.2023**).
**199-ФЗ от 26.06.2026** добавил штрафы за нарушение (ст. 13.55 и 13.56 КоАП). Бюджет — 0 ₽, команда — школьники.

## Решение

- **Better Auth** — библиотека внутри нашего API (без внешнего сервиса и лимита пользователей), сессии в Neon (ADR 0003).
- Провайдеры: **VK ID** (встроенный провайдер Better Auth) и **Яндекс ID** (через Generic OAuth).
- **Входов через Google, Apple, GitHub нет** — для пользователей из РФ это нарушение указанной нормы.
- Вход по почте не делаем: SMTP на бесплатном Render закрыт, а российский вход закрывает задачу без почты.
- Гостевой режим остаётся основным: аккаунт нужен только для синхронизации между устройствами.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Auth.js / Clerk / Supabase Auth | Внешние сервисы или слабая поддержка VK ID / Яндекс ID; данные вне нашего контроля |
| Вход по номеру телефона | SMS стоят денег |
| Госуслуги (ЕСИА) | Подключение требует юрлица и аккредитации |

## Последствия

- Секреты OAuth (`VK_CLIENT_*`, `YANDEX_CLIENT_*`, `BETTER_AUTH_SECRET`) — только в настройках Render (`.env.example` без значений).
- Перед запуском аккаунтов — проверка требований к согласию и возрасту (D-009) взрослым/школой.
