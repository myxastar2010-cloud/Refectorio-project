# @refectorio/contracts

Общие схемы данных (zod 4) между частями проекта: тест их записывает, будущее меню — читает. Несовместимая форма получает
новую версию, старая остаётся читаемой.

| Схема | Что описывает |
|---|---|
| `QuizAnswersV1` (`src/quiz.ts`) | ответы теста: цель, тело, здоровье (чипы и свободный текст), аллергии, неприязнь, активность, образ жизни, доп. цели (этап 3, необязательное поле), решения игры |
| `toQuestionnaireInput` | перевод ответов в вход `nutrition-core` (с проверками) |
| `TasteProfileV1` (`src/taste.ts`) | профиль вкуса после игры: версия каталога, ответы, подсказки |

Каждая ветка схем покрыта тестами на 100 % (`npm run test:coverage`).
