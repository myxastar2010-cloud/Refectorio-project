# ADR 0005 · ИИ-шлюз: модель — настройка, числа — из кода, алгоритм без ИИ — полноценный путь

- Статус: принято (реализация — этапы 2–3) · 02.10.2026
- Связано: R11, R10, `research/ai-strategy.md`, `research/conflicts.md` C-03, D-011

## Контекст

Чат-боты ошибаются в цифрах питания (в исследовании BMC Nephrology 2026 лучший попадал в калорийность меню в 42% случаев).
Бесплатные лимиты провайдеров малы и ненадёжны; по данным R11 (октябрь 2026) NVIDIA NIM не принимает номера +7 при
верификации, а OpenRouter блокирует аккаунты и IP из РФ.

## Решение

1. **ИИ не считает цифры.** Код (`packages/nutrition-core`) считает нормы и порции; ИИ получает уже отфильтрованный список блюд
   (ID + теги) и возвращает **только выбор ID и короткие тексты** по JSON-схеме (`response_format: json_schema`, strict).
   Модели прямо запрещено писать числа КБЖУ.
2. **Валидатор** проверяет каждый ответ: схема, существование ID, аллергены и режим питания (повторно), допуски по калориям
   и белку после подбора порций решателем, повторы. При ошибке — до 2 повторов с перечнем ошибок, затем **алгоритм без ИИ**
   (решатель HiGHS + эвристика, R10) — он полноценный, а не аварийный: меню собирается всегда.
3. **Цепочка провайдеров — конфигурация, а не код:** основная модель DeepSeek V4.1 Flash; резерв — GLM-5.3 или Kimi K3;
   запасной путь — бесплатные модели OpenRouter; последний рубеж — алгоритм. Конкретные провайдеры подтверждаются
   эмпирически с сервера Render (Frankfurt) перед этапом 3; возможна небольшая оплата прямого API DeepSeek (решение команды).
4. **Защита:** свободные поля анкеты — справочник + короткое поле ≤ 150 символов; их текст передаётся модели как данные
   (в отдельном поле, экранированно), а не как инструкции. Худший исход инъекции — невалидный ID, который ловит валидатор.
5. **Кэш и лимиты:** кэш ответов по хэшу обезличенной анкеты; лимит запросов на IP и ALTCHA (самохостинговая капча);
   при исчерпании лимитов — сразу алгоритм.
6. **Без fine-tuning:** промпт + схема + примеры + эталонные персоны как регрессионные тесты (≥ 60, `test-personas.json`).

## Последствия

- Качество и смена модели измеряются на эталонных персонах (доля валидного JSON, нарушения ограничений, русский язык, задержка).
- Ключи провайдеров — только в переменных окружения Render; в браузер не попадают.
