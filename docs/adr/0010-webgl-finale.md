# ADR 0010 · Финал теста: жидкое ядро на WebGL2 с CSS-запасным вариантом

- Статус: **заменено ADR 0013** (24.10.2026, этап 3 §7: история из линейных рисунков на Canvas 2D); было принято 10.10.2026
- Связано: ТЗ этапа 2 (§12), ADR 0006 (анимации), `apps/web/src/features/quiz/finale/`, `motion/tokens.ts` (`FINALE`)

## Контекст

После последнего ответа тест «генерирует меню» (на этапе 2 — бесконечно, честно об этом сообщая через 40 с).
Экран должен быть «невероятно динамичным, сложным и необычным»: полоса прогресса превращается в красную точку,
точка — в живое ядро, вокруг меняются подписи, еда с фона медленно втягивается в ядро. Для этапа 3 нужна волна,
открывающая готовое меню. Цели те же, что на главной: 60 fps на ноутбуке команды (1536×730, DPR 1,25, Intel Iris Xe),
без долгих задач, с reduced motion и без лишнего веса на главной.

## Решение

1. **Ядро — фрагментный шейдер WebGL2** (`finale/coreGl.ts`): одно тело и четыре капли на наклонных орбитах
   сливаются и разделяются (гладкий минимум расстояний), объём рисуется светом, ободком и бликом по куполообразной
   нормали; три спутника проходят перед и за ядром; смена подписи — рябь и короткое «вздутие». Один треугольник на весь
   холст, один вызов отрисовки за кадр, холст ≤ ≈ 520 CSS px, DPR ≤ 2.
2. **Бесшовная передача:** при `intro = 0` шейдер рисует ровно ту плоскую красную точку, в которую сжалась полоса
   (тот же цвет и размер), и «вырастает» из неё в ядро.
3. **Подписи** (`finale/Captions.tsx`) — пилюля из трёх частей, которая меняет ширину только `transform`
   (не анимируя `width`), текст и иконка входят и выходят пружиной Motion; последняя подпись остаётся с бегущим
   бликом. Скринридер слышит только первую и последнюю подпись.
4. **Еда втягивается в ядро** режимом «притяжения» движка еды: спираль, растворение и новое появление на краях —
   только `transform` и `opacity`.
5. **Волна раскрытия** (`finale/revealGl.ts`, `?reveal=demo`) — полноэкранный шейдер ≤ ≈ 1,6 с с маской-кругом
   (`clip-path`) по фронту; без WebGL2 — CSS-круг с мягким кольцом, с reduced motion — перекрёстное затухание.
6. **Ленивая загрузка:** финал (`Finale`), ядро (`coreGl`) и волна (`revealGl`) — отдельные чанки (≈ 5 + 2,4 + 1,2 КБ
   gzip), подгружаются в простое на последних шагах. Рендер останавливается, когда холст не виден или вкладка
   скрыта; потеря контекста WebGL обрабатывается.
7. **Запасной вариант без WebGL2, при `saveData` или reduced motion** (`finale/Core.tsx`): CSS-градиент той же формы
   с мягкой пульсацией прозрачности.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Lottie / видео | Тяжелее и неживое: не реагирует на подписи, не передаётся бесшовно из полосы прогресса |
| SVG-фильтр «gooey» (blur + contrast) | Живой `filter` на каждом кадре — дорогой на слабых видеокартах (урок D-022/D-028) |
| Three.js | +150 КБ ради одного полноэкранного треугольника |
| CSS-капли с `border-radius` | Нет слияния и разделения, нет объёма — «недостаточно необычно» по ТЗ |

## Последствия

- Шейдеры небольшие и прокомментированы в коде; параметры движения (орбиты, радиусы, рябь) — константы шейдера,
  тайминги — в `FINALE` (`motion/tokens.ts`).
- Проверки: e2e доходит до финала во всех движках (WebGL2 и запасной путь), reduced motion — без шейдера; замер FPS
  и трассировки GPU — в отчёте этапа 2.
