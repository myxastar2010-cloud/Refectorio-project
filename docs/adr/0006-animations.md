# ADR 0006 · Анимации: Motion + собственный движок летающей еды

- Статус: принято · 02.10.2026
- Связано: ТЗ этапа 1 (раздел 6), `docs/design-system.md` (раздел «Движение»), `apps/web/src/motion/tokens.ts`

## Контекст

Главная живёт за счёт движения: 10–14 предметов еды постоянно летают, «камера» переключает сцены, иконка команды раскрывается
в карточку как приложение в iOS, кнопки заливаются «волной», карточки наклоняются за курсором. Цель — 60 fps на среднем ноутбуке,
≥ 45 fps при 4× замедлении CPU, без долгих задач > 50 мс и с поддержкой reduced motion.

## Решение

- **Motion 13** для UI-анимаций: пружины, `layoutId` (shared element с анимацией радиуса без искажений), `AnimatePresence`,
  `MotionConfig reducedMotion="user"`; подключение через `LazyMotion` + `domMax`, в компонентах — `m.*`.
- **Летающая еда — собственный движок** `engine/food-field` на чистом TypeScript: один цикл `requestAnimationFrame`, состояние
  в обычных объектах, запись напрямую в `style.transform` (`translate3d + rotate + scale`), шаг времени ≤ 50 мс, пауза при
  скрытой вкладке, автоматическое понижение качества при < 50 fps, детерминизм по seed (для тестов). React — тонкая обёртка.
- **Размытие еды во второй части** — заранее размытые спрайты с перекрёстным затуханием, а не живой `filter: blur`
  (живой блюр движущихся слоёв «роняет» fps на слабых устройствах).
- **Волна** — `clip-path: circle()` от точки входа курсора на копии содержимого; **наклон** — `transform: rotateX/Y` на пружине,
  блик — радиальный градиент; только `(hover: hover) and (pointer: fine)`.
- Анимируются только `transform`, `opacity` и кратко `filter`.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| GSAP 3.15 (бесплатен с 2025) | Отличный таймлайн, но вторая библиотека; Motion закрывает задачи. Подключим только при доказанной необходимости |
| Физический движок (matter.js и т. п.) | Предметы не сталкиваются по ТЗ; тяжело и лишне |
| Canvas/WebGL для еды | Сложнее доступность, клики по альфа-маске и резкость; DOM + transform даёт 60 fps на 14 спрайтах |
| View Transitions (React 19.3 `ViewTransition`) | Не прерываемы так гибко, как пружины Motion; оставлено как вариант, если окажется плавнее |

## Последствия

- Все тайминги — в токенах; движок покрыт юнит-тестами математики (отталкивание, возврат из-за края, импульс, альфа-маска, seed).
- Режимы `?seed=`, `?freeze=1`, `?pose=design` — только по параметру адреса, для тестов и сравнения с макетами.
