# Фронтенд (`apps/web`)

## React и TypeScript

- Функциональные компоненты, именованные экспорты. Пропсы — через `type Props = {...}`; `React.FC` не используем.
- Хуки — по правилам `eslint-plugin-react-hooks` (без подавления предупреждений).
- Состояние, которое меняется каждый кадр (позиции еды, наклон, координаты волны), — в `useRef` и прямой записи в `element.style`,
  а не в `useState`: иначе 60 перерисовок React в секунду.
- Побочные эффекты с подписками (`resize`, `wheel`, `keydown`, `pointer*`) — с очисткой в `return` эффекта; обработчики `wheel`
  и `touchmove`, которые вызывают `preventDefault`, регистрируются с `{ passive: false }`.
- Ленивая загрузка тяжёлого: раскрытая карточка команды — `React.lazy`, если заметно уменьшает стартовый бандл.

## Стили

- Tailwind 4: токены объявлены в `src/styles/tokens.css` (`@theme`). Произвольные значения `[...]` — только через CSS-переменные токенов.
- Масштаб десктопа — единица `--s = min(100vw / 1920, 100svh / 1080)`; размеры из макета записываются как `calc(N * var(--s))`.
- Высоты — `svh`/`dvh`, отступы от вырезов экрана — `env(safe-area-inset-*)`.
- Классы собираем через `clsx`; порядок классов упорядочивает `prettier-plugin-tailwindcss`.

## Картинки и шрифт

- Картинки — только из `src/assets/generated/` (AVIF/WebP, 1× и 2×), через манифест. Исходники — `assets-src/`, пересборка `npm run assets`.
- Файлы из `public/` — через `import.meta.env.BASE_URL` (сайт живёт и на `/`, и на `/Refectorio-project/` — Pages).
- Open Runde подключается в `styles/fonts.css` (подмножества из `npm run fonts`); 600 и 700 предзагружаются; `font-display: swap`
  + метрики-запаска против сдвига макета.

## Контент

- Все строки — в `src/content/site.ru.ts` (zod-схема проверяет его в тестах). Компонент получает тексты через пропсы или импорт контента.

## Сцены и ввод

- Состояния сцен: `hero` и `about` (`#about`). Кнопка «Назад» браузера работает. Во время перехода ввод заблокирован.
- Клавиши листают сцены, кроме случаев, когда клавиша нужна самому элементу в фокусе: поля ввода забирают все клавиши,
  кнопки и ссылки — только Пробел (он их нажимает); стрелки, Page Up/Down, Home/End листают сцены и с кнопки в фокусе.
