# ADR 0012 · Анимация генерации: история из линейных рисунков на Canvas 2D

- Статус: принято · 24.10.2026, дополнено 25.10 (тележка вместо робота, диск точек, темп) · **заменяет ADR 0010**
  (жидкое ядро WebGL2)
- Связано: ТЗ этапа 3 (§7), ADR 0006 (анимации), `apps/web/src/features/quiz/finale/story/`, `scripts/story/`,
  `motion/tokens.ts` (`STORY`, `FINALE`), решения D-056 (описание блюд), журнал `progress/stage-3.md`

## Контекст

Команда оценила ядро этапа 2 как «просто метаболы, никакой сложности». Нужна многоступенчатая 2D-история в линейной
графике: блокнот с карандашом → лупа над вращающейся планетой в сети → башенный кран ставит блок в интерфейс → робот-
доставщик на дороге (25.10 пользователь заменил его тележкой из магазина, «как будто её кто-то запустил») → свои
сцены → точки, которые крутятся бесконечно (по образцу видео команды). Еда в это время летает
размыто, как на других шагах, — притяжение еды к ядру (этап 2) убирается. Цели прежние: 60 fps на ноутбуке команды,
≥ 45 fps при 4× замедлении, без долгих задач, reduced motion, ленивый чанк ≤ 30 КБ gz.

## Решение

1. **Canvas 2D, один `requestAnimationFrame`, DPR ≤ 2, `aria-hidden`.** Подписи остаются живой областью. Пауза при
   `document.hidden` и под честной строкой (WCAG 2.2.2). SVG не нужен: ≈ 3 000 точек линий и ≤ 240 точек облака за
   кадр Canvas рисует быстрее, чем DOM пересчитывает SVG.
2. **Рисунки — оригинальные линии в квадрате 512 единиц** (`scripts/story/drawings.mjs`): на сетке, симметричные,
   внутри безопасной зоны ±176 (сборка проверяет); одна пара толщин (5,5 и 3,5 единицы), круглые концы, палитра сайта (чёрный, `#5A5451`, акцент `#E63946`). Кривые разворачиваются в ломаные
   **при сборке** (`npm run story`): координаты по 1/8 единицы, int16, разности — `story-data.json` (12,5 КБ gz на пять
   рисунков). Там же два облака по 240 точек на рисунок: «из чего он собирается» (только видимые сначала линии) и «во
   что рассыпается» (все). В браузере пути не измеряются.
3. **Сцены — код с частями** (`scenes.ts`, `laterScenes.ts`): каждая сцена двигает свои части матрицами (карандаш по
   строкам с паузами между словами и «прыжками» на новую строку, лупа по дуге с наклоном, стрела крана «доворачивается»
   к нам — сжатие по x, — трос, раскачка груза с затуханием, сплющивание блока при посадке; тележку оттягивают и отпускают — она
   катится, замедляясь, разворачивается вокруг себя (ширина по косинусу угла, линии при этом не тоньшают — точки
   двигаются матрицей, перо нет), покачивается на остановке, продукты подпрыгивают; крышка на петле, язычки пламени).
   Последний кадр каждой сцены совпадает с первым кадром её облака «на выход».
4. **Превращение** (`morph.ts`, 1,7 с) — три такта: старый рисунок гаснет, на его линиях появляются точки; точки
   собираются в кольцо — каждая в ячейку своего угла вокруг центра, поэтому поток радиальный и спокойный; кольцо один
   раз поворачивается и чуть «дышит»; затем раскрывается в точки нового рисунка с лёгким перелётом, и рисунок
   дорисовывается волной. Все точки — акцентного цвета, одного размера.
5. **Временная шкала** (`timeline.ts`, юнит-тесты): сцены и превращения подряд, последняя сцена — петля; подписи —
   метки внутри сцен. Часы истории идут в `STORY.speed` = 1,15 раза быстрее настенных (25.10: «чуть быстрее, динамичнее») — первый проход
   ≈ 23 с. Тестовый крючок `?story=<сцена>` (только тестовые сборки).
6. **Точки** (по видео команды, переделано 25.10): плоский диск белых точек кольцами (6 колец по 6k точек) поворачивается
   в пространстве — анфас круг из концентрических колец, боком узкая линза; перспектива — ближний край крупнее.
   Сторона, куда смотрит диск, обходит эллипс вокруг взгляда раз за петлю (5,2 с часов истории), точки скользят на
   шестую часть оборота — петля бесшовная. Свечение: широкая дымка из трёх медленных пятен, яркое ядро на стороне,
   куда смотрит диск (за кругом анфас, рядом с линзой боком), и тёплое пятно напротив. Пятна — градиенты с плавным
   («гауссовым») спадом до нуля, нарисованные один раз в маленькие спрайты и растянутые (дешевле, чем заливать градиент
   каждый кадр), без blur.
7. **Передача от полосы прогресса** — как на этапе 2 (полоса сжимается в точку и летит в центр), точка становится
   кончиком карандаша. Передача запускается один раз (раньше вторая точка пролетала поверх).
8. **Адаптивное качество:** если кадры в среднем дольше 20 мс, следующие превращения идут с половиной точек.
9. **Reduced motion:** каждый рисунок — неподвижный, смена перекрёстным затуханием 0,4 с каждые 3 с; точки — тихое
   «дыхание» прозрачности.
10. **Удалено:** `Core.tsx`, `coreGl.ts` и их чанк; `attractorChannel.ts`, `ATTRACT`/`attractVelocity`/
    `dissolveOpacity`/`edgePoint` в `engine/food-field/math.ts` (+ тесты), растворение и возрождение еды в
    `engine.ts`. `gl.ts` и `revealGl.ts` остаются — волна-демо `?reveal=demo` раскрывается из центра композиции.

## Последствия

- Чанк истории 6,8 КБ (код) + 12,5 КБ (рисунки) gz; WebGL в генерации больше нет — меньше рисков на слабых видеокартах.
- Новые рисунки добавляются в `drawings.mjs` и `laterScenes.ts`; `npm run story` пересобирает данные.
- Минусы: сцены — ручной код (у каждой своя «режиссура»); смена порядка сцен требует проверить подписи (`captionPlan`
  и `quiz.ru.ts` `finale.captions`).
