# Анимации (Motion 13 и собственный движок)

## Библиотека

- Импорт только из `motion/react`. Корень приложения: `LazyMotion features={domAnimation} strict` + `MotionConfig reducedMotion="user"`;
  в компонентах — `m.div`, а не `motion.div` (иначе LazyMotion не уменьшит бандл).
- Раскрытие карточки команды — свой морф по четырём углам (`features/team-dialog/morph.ts`, `useCornerMorph`): карточка
  в итоговом размере, проективное преобразование, пружины без отскока; радиус пересчитывается под растяжение, фон
  «стыкуется» со звездой значка (`DIALOG.starDock`). `layoutId` Motion не используется.
- Вторую анимационную библиотеку (GSAP) не подключать без доказанной необходимости.

## Токены

- Пружины, длительности, кривые и задержки каскада — только из `src/motion/tokens.ts` (зеркало CSS-переменных из `tokens.css`).
- Базовая кривая — `cubic-bezier(0.16, 1, 0.3, 1)`; микроанимации 200–350 мс; смена сцен ≈1,15 с; каскад 40–80 мс.

## Производительность

- Анимировать только `transform`, `opacity` и кратко `filter`; `clip-path` — только для волны на небольших элементах.
- Размытие движущейся еды — заранее размытые спрайты с перекрёстным затуханием, а не живой `filter: blur`.
- Один цикл `requestAnimationFrame` на весь движок еды; шаг времени ограничен 50 мс; пауза при `document.hidden`.
- Замер FPS в первые 2 с и понижение качества при < 50 fps.

## Прерываемость и ввод

- Любая анимация прерывается: повторный клик во время раскрытия разворачивает его обратно, быстрые входы и выходы курсора не мерцают.
- Колесо и тачпад: одно движение — ровно один переход (накопление `deltaY` + «глушитель инерции»).

## Reduced motion

- `prefers-reduced-motion: reduce` → мгновенная смена сцен с затуханием 200 мс, еда без дрейфа, без наклона и блика.
- Также учитывать `navigator.connection.saveData`.

## Проверка

- Юнит-тесты математики движка; e2e с `page.emulateMedia({ reducedMotion: 'reduce' })`; видео переходов; замер FPS.
